# libro-include

`book` con `\include` en subcarpetas y nombres con tildes y espacios (`Capítulos/Desarrollo/Análisis de datos.tex`), con referencias cruzadas hacia atrás y hacia adelante entre capítulos. Cubre `\includeonly`, el aislamiento y el sembrado de `.aux`, y el grafo de inclusión. Los fuentes van con CRLF, como el libro.
